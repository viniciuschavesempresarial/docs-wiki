# História de Usuário

EU COMO Usuário Leitor ou Pesquisador da plataforma Docs-Wiki,  
GOSTARIA DE selecionar um ou mais documentos técnicos no painel lateral do chat e submeter perguntas em linguagem natural para receber respostas estritamente fundamentadas (grounded) via modelo Google Gemini com citações de fontes,  
PARA QUE eu possa tirar dúvidas complexas e extrair insights precisos do acervo técnico sem riscos de alucinação de dados.  

# Escopo

- Interface interativa de chat (/ai-chat) com componente DocumentSelector permitindo a seleção granular de 1 ou múltiplos materiais técnicos antes do envio de perguntas.
- Validação no frontend e backend garantindo que pelo menos um documento esteja selecionado, alertando o usuário caso tente interagir sem contexto.
- Geração de vetor de 768 dimensões para a pergunta do usuário e recuperação dos top 8 chunks mais similares via pgvector (material_id IN selected_ids) ordenados por distância Euclidiana/Cosseno.
- Montagem de prompt de Grounding estruturado com blocos delimitados por [Doc: X - Seção: Y], mapeamento de fontes e instruções estritas para evitar alucinações.
- Integração com a API do Google Gemini (temperatura 0.2, topP 0.8), sanitização do output com DOMPurify e renderização das citações (ChatSourceCitation).

# Não Escopo

- Treinamento customizado ou fine-tuning de modelos generativos na infraestrutura do cliente.
- Upload de arquivos arbitrários fora dos materiais técnicos já indexados na plataforma.
- Histórico de conversação multi-turn ilimitado persistido em banco sem expurgo de sessão.

# Critérios de Aceite

**CA01 - Chat RAG com Grounding Estrito e Citação de Fontes [Cobre: SC-001]**  
- **Dado** que o usuário selecionou 1 ou mais documentos no DocumentSelector e enviou uma pergunta  
- **Quando** o backend recuperar os top 8 chunks via pgvector e submeter o prompt de Grounding ao Gemini (temp: 0.2)  
- **Então** a API deve retornar HTTP 200 OK contendo a resposta 'answer' e o array 'sources' com as citações das seções utilizadas  
- **E** o frontend deve aplicar sanitização DOMPurify  
- **E** renderizar os badges de citação com links diretos para as seções de origem  

**CA02 - Alerta de Seleção Obrigatória de Documento no Painel Lateral [Cobre: SC-002]**  
- **Dado** que o usuário está na tela '/ai-chat' sem nenhum documento selecionado no painel lateral  
- **Quando** o usuário tentar submeter uma pergunta na caixa de texto do chat  
- **Então** o sistema deve exibir a mensagem de alerta 'Alerta: Selecione ao menos um documento no painel lateral'  
- **E** bloquear o envio da requisição mantendo o foco no seletor de documentos  

**CA03 - Tratamento de Falha na API Gemini e Resposta Fallback [Cobre: SC-001]**  
- **Dado** que o Gemini SDK ou a API externa retorne erro de comunicação ou timeout  
- **Quando** o chat-service interceptar a falha  
- **Então** deve responder com HTTP 500 ou mensagem estruturada de fallback amigável  
- **E** registrar o log de erro detalhado para observabilidade  
- **E** permitir nova tentativa pelo usuário na interface
